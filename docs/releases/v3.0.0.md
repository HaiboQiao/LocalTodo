LocalTodo 3.0.0 是第三个主版本，重点完善了持续任务、日期选择、桌面部件、多窗口一致性，以及每周计划和成长记录的日常操作体验。

## 主要变化

- 新增持续日期任务：截止前持续出现在“今天”，到期后进入“已过期”。
- 所有任务与成果日期改为整框打开日历，日期文字只读并提供清除入口。
- 桌面任务列表和四象限不再强制置顶，也不会在主窗口收起时突然跳到最前方。
- 重复启动程序会唤醒已有实例，避免多个进程同时操作同一数据库。
- 加强任务完成、删除和多窗口编辑时的数据一致性。
- 完善成长记录的分类默认值、分类排序、跨年度时间轴及拖动操作。
- 完善每周计划的拖动、`Ctrl` 复制、键盘删除和取消选中操作。

## 安装与更新

新用户完整解压便携包后运行 `LocalTodo.exe` 即可，无需安装 .NET。

旧版本更新前请从系统托盘完全退出 LocalTodo，并备份原目录中的 `Data` 和 `Backups`。随后替换 7 个程序文件，同时保留原有数据目录。

## 数据兼容

本版本数据库结构为 v13。v12 → v13 只增加持续日期标记，旧任务默认关闭该功能，原有任务日期、提醒、循环、完成状态和成长记录不会被该迁移修改。升级前程序会执行完整性检查并创建安全备份。
